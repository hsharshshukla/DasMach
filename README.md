# DasMach

A Django-based prototype for a used-car marketplace, created to explore end-to-end web application development around vehicle discovery, listing, and marketplace workflows.

## Overview

DasMach is an early full-stack development project focused on understanding how a marketplace-style application connects a web interface with backend application logic.

The project explores the foundations behind platforms where users can browse vehicles and submit vehicle information for sale.

It represents an earlier stage of my software-development journey and is retained as part of my engineering portfolio to show the progression from web application development toward backend systems, platform engineering, and AI-enabled applications.

## Core Areas Explored

- Django-based web application development
- Backend routing and views
- Server-rendered web pages
- Vehicle listing and upload workflows
- Form-based user interactions
- Application structure using Django conventions
- Integration between frontend templates and backend logic
- Git-based source control
